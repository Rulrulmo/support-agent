# 평가셋

| 파일 | 내용 |
|---|---|
| `v0.jsonl` | 60문항 (한국어 45 · 영어 15). Apache Guacamole 1.6.0 매뉴얼 기준 |
| `check.py` | 형식·값 목록·중복 검사 + 근거 절이 발행된 매뉴얼에 실제로 있는지 확인 |

## 문항 형식
| 필드 | 설명 |
|---|---|
| `question` | 상담 채팅에 실제로 올 법한 질문. 한국어 질문 약 20개는 증상만 말한다 (어떤 절을 봐야 하는지 스스로 찾아야 한다) |
| `expected_key_points` | 정답에 **반드시** 들어가야 할 사실 (매뉴얼에 있는 것만) |
| `must_not` | 틀린 답이 하기 쉬운 말 (예: RDP 색상 깊이에 VNC 값 32를 권함) |
| `sources` | 근거 절 `{page, anchor}`: 검색 평가의 정답. 검색 결과가 이 절이거나 그 하위 절이면 맞다 |
| `expected_behavior` | answer 49 · clarify(되묻기) 4 · handoff(사람 연결) 3 · refuse_unknown(매뉴얼에 없음, 지어내지 않기) 4 |
| `category`, `difficulty` | 문제해결 10 · 인증 10 · 관리 8 · 설정 7 · 설치 7 · 사용법 6 · 기타 6 · 연결·화면 4 · 보안 2 / easy 10 · medium 33 · hard 17 |

## 한계
- **LLM이 매뉴얼을 읽고 쓴 초안**이다. 근거 절이 실제로 있는지는 `check.py`로 확인했지만, 질문의 자연스러움과 요점의 정확성은 사람이 다시 봐야 한다
- LLM이 만든 질문을 LLM으로 답하면 점수가 높게 나오기 쉽다 → 증상형·구어체·오타 질문을 섞었고, 수치는 "같은 평가셋에서의 전후 비교"로만 쓴다
